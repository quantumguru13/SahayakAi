# 🤝 Sahayak AI
### AI-Powered Humanitarian Case Intelligence Platform

> Empowering NGOs to spend less time on paperwork and more time helping people.

---

## 📖 About the Project

Sahayak AI is an AI-powered platform designed to help NGOs and social welfare organizations manage beneficiary cases more efficiently.

Field workers often deal with large volumes of documents such as medical reports, identity proofs, income certificates, and government forms. Extracting information manually is time-consuming and prone to errors, which delays support for people who need urgent assistance.

Sahayak AI automates this workflow by using AI to extract structured information from uploaded documents, prioritize beneficiaries based on urgency, recommend relevant government welfare schemes, and generate reports for field teams and donors.

The goal is simple:

> **Reduce administrative work so NGOs can focus on making a greater social impact.**

---

## 🚨 Problem Statement

NGOs across India face several operational challenges:

- Manual data entry from beneficiary documents
- Time-consuming verification processes
- Difficulty identifying high-priority cases
- Limited awareness of eligible government schemes
- Hours spent preparing donor and impact reports
- Fragmented beneficiary information across multiple documents

These issues slow down decision-making and reduce the overall effectiveness of humanitarian work.

---

## 💡 Our Solution

Sahayak AI provides an intelligent workflow that transforms unstructured documents into meaningful insights.

The platform can:

- Extract structured information from uploaded documents
- Create complete beneficiary profiles
- Automatically assess case urgency
- Recommend suitable government welfare schemes
- Generate daily field briefs
- Produce donor-ready impact reports
- Organize all beneficiary information in one place

This enables NGOs to respond faster while reducing paperwork and operational overhead.

---

# ✨ Key Features

### 📄 Smart Document Processing

Upload medical reports, Aadhaar cards, income certificates, disability certificates, and other beneficiary documents.

AI automatically extracts important details without manual data entry.

---

### 👤 Beneficiary Profile Generation

Creates a structured beneficiary profile from multiple uploaded documents.

Includes information such as:

- Personal details
- Medical conditions
- Financial background
- Family information
- Required assistance

---

### ⚡ Priority Assessment

Every case receives a priority score based on predefined humanitarian factors.

Cases are categorized into:

- 🔴 High Priority
- 🟠 Medium Priority
- 🟢 Low Priority

This helps field workers focus on beneficiaries who need immediate support.

---

### 🏛 Government Scheme Recommendations

Suggests relevant government welfare schemes based on the beneficiary profile.

Recommendations consider factors such as:

- Income
- Disability
- Age
- Medical conditions
- Family status

---

### 📊 NGO Dashboard

Provides a centralized dashboard for monitoring:

- Total beneficiaries
- High-priority cases
- Pending reviews
- Recently uploaded documents
- Daily summaries

---

### 📑 Automated Reports

Generate professional reports for:

- NGO management
- Field workers
- Donors
- CSR partners

Reports summarize beneficiary progress and organizational impact.

---

### 🔒 Secure & Privacy Focused

Sensitive beneficiary data is protected using secure authentication and role-based access control.

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/your-username/sahayak-ai.git
```

## Frontend

```bash
cd frontend

npm install

npm run dev
```

---

## Backend

```bash
cd backend

pip install -r requirements.txt

uvicorn app.main:app --reload
```
